# Air Race Ocean Run

Conceptual 3D air-racing game for a promotional-screen portfolio piece. The project is an independent Unity 6 URP project and does not modify the earlier car project.

## Current direction

- A broad, closed-loop air-race course over open ocean.
- Six paired pylons act as sequential checkpoints; a distinct seventh marker is the finish.
- The first level has a 60-second time limit. Later levels may be longer and are out of scope for the first course build.
- The aircraft is controlled with WASD using smooth, arcade-simulation movement. Space triggers barrel-roll stunts after a can is collected.
- Wwise is deferred until the visual environment and gameplay are in place.

## Unity project

- Unity: 6000.3.10f1
- Render pipeline: Universal Render Pipeline (URP)
- Project root: this folder
- Start scene: to be created in the map-first phase

## Production order

1. Lock visual direction and record approved asset sources.
2. Organize and import environment assets.
3. Build and review the ocean course map without the aircraft.
4. Integrate the selected aerobatic aircraft and controls.
5. Implement scoring, energy, retry flow, UI, and polish.
6. Integrate Wwise last.
