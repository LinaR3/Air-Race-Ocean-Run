# Level 01 map scene

`AirRace_Level01_Map.unity` is the first editable course scene. It contains a broad closed ocean loop, six ordered paired gates, and a visually distinct finish marker near the start.

The pylon mesh, ocean color and route line in this first pass are explicitly blockout materials/geometry. They are temporary scene scaffolding and must be replaced/refined against the approved Kenney pylon, Swim Raft, A.U.R.W. water, and selected skybox. The route positions are first-pass tuning values, not final difficulty.

The aircraft is intentionally omitted from this map-first scene. Test the aircraft in a separate scene after converting the approved Blender source to an importable Unity model.
